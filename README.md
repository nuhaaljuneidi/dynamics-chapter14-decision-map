# Chapter 14: Force, Mass, and Acceleration Decision Map

An interactive decision map for selecting a solution strategy for particle kinetics problems from Bedford and Fowler's *Engineering Mechanics: Dynamics*, Chapter 14.

Developed by **Dr. Nuha Aljuneidi** for engineering education and independent study.

## Live resource

[Open the Chapter 14 decision map](https://nuhaaljuneidi.github.io/dynamics-chapter14-decision-map/)

## Learning purpose

The map helps students move from a problem statement to an appropriate free-body diagram, coordinate system, governing equation, and solution procedure. It emphasizes the connection between force, mass, acceleration, and the geometry of the motion.

## Recommended workflow

1. Identify the particle and draw its free-body diagram.
2. Select Cartesian, normal-tangential, or polar coordinates based on the path description.
3. Resolve forces and acceleration components consistently.
4. Apply Newton's second law in each required direction.
5. Check units, signs, and whether the result is physically reasonable.

## Map structure

The map branches from Newton's second law into a **system of particles** or a **single particle**. Both paths converge on the same coordinate-system decision, which then resolves into one of three leaves:

- **Cartesian coordinates** (&sect;14.2)
- **Normal & tangential components** (&sect;14.3)
- **Polar & cylindrical coordinates** (&sect;14.4), which also covers **orbital mechanics** (&sect;14.5) as a special case where the only radial force is gravity
